## :gear: Description
Ce projet vise à recréer un site complet d'un ou d'une chaine de restaurant.
L'objectif est de gérer à la fois les clients, le personnels et les livreurs.
Par conséquent le site doit être responsive. 

## :toolbox: Prérequis
- internet (facultatif)
- php

## :rocket: Téléchargement et compilation
### Téléchargement
```bash
git clone https://github.com/cardotbutzneo/Creative-Yumland-MI4-C
```
### lancement
````bash
php -S localhost:[port valide]
````
Exemple valide :
```bash
php -S localhost:7180
```
